# Brighton and New Year: activity packets

Ten speaking-based activities about Brighton and the new year (future plans:
*going to*, *will*, *want to*), in two levels. Teachers use them in any order.

**How each packet works:** print the whole file. The **first page is the
teacher notes** (time, prep, steps, ideas); the pages after it are for
students. Files ending in **ANSWERS** are the same pages with the answers
in **red**. Start with **00 Overview** for the activity menu and Kahoot links.

Tap **PDF** to read on GitHub; tap **Word** then download to edit or print.
